# Requisitos académicos

El enunciado original solicita informe DOC o PDF y cálculos en Excel o Python, al menos 61 precios ajustados mensuales, CAPM por activo con significancia y SML virtual, y una cartera con pesos no nulos que sumen uno, analizada mediante FF3. Aunque el texto original menciona cuatro activos, el profesor ha aprobado utilizar seis.

No prescribe errores HAC ni fija en su contenido una fecha de entrega vigente. El proyecto utiliza OLS como inferencia principal y HAC como sensibilidad. La entrega documental se realiza en PDF, con fuentes LaTeX editables.

El enunciado actualizado permite un notebook integrado como alternativa al informe y al fichero de datos. Aquí se mantiene informe PDF con Excel/Python y se prepara una presentación Beamer independiente. 

El enunciado y los materiales docentes se conservan localmente y no se redistribuyen en este repositorio.
